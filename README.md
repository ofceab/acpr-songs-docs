# Recueil ACPR - site public

Pages publiques de l'application Recueil ACPR, servies par GitHub Pages à https://ofceab.github.io/acpr-songs-docs/.

- `index.html` : page de présentation.
- `privacy-policy.html` : politique de confidentialité (français et anglais), URL déclarée sur Google Play.

Le texte source de la politique est `apps/mobile/store/policy/privacy-policy.md` dans le dépôt `acpr-song-monorepo`.
Après une modification, régénérer le HTML avec `store/tools/build_privacy_html.py` puis copier le fichier ici.
